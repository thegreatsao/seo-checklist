## Scope

1. **The producer in the blind input** (ruling 1 of 2026-10-24). A script that only reads JSON another program wrote
   is judged with that program in view. `audit_item_readings.py` names, per such script, where its producer lives —
   `rendered_audit.py` and `html_validator.py` (whose `html` key the same snippet writes): `SKILL.md`, the code block
   under `## Measuring the rendered page` — and `--blind` prints that code once, after the script's source, labelled
   as the producer of the script's input. A named section or block that is not found is an error, not an empty
   block. The brief tells the reader that a producer's computation counts as the script's own.
   Not in scope: `cwv_metrics.py`, whose input an agent writes from trace insights by hand (no code to show); it is
   named in the batch-4 brief.
2. **The brief asks for English answers** (batch 2: Codex answered the review in Russian).
3. **Two findings on batches 1–2, fixed red-first before any second reading is entered** (a review of
   `0b97a4b..9865e40` by the F03 owner session; the owner: "Передай находки 1 и 2 сессии f03-batch3: пусть починит
   red-first до того, как вносить 29 вторых прочтений" — pass findings 1 and 2 to this batch, fixed red-first before
   the 29 readings are entered):
   - *The digest leaves out the code the reader judged.* `digest()` hashes title, check, `measures` and the first
     reading, but the reader is shown the script's source (and now its producer), so an edited script — F15's
     `parse_html.py` repair, say — leaves every record of that script current. Fixed: the digest also covers the
     script's source and its producer's code. Imported helpers are not covered (why: below, in Results).
   - *The digest is taken at entry, not at reading.* The brief had `read` taken by `--digest ID` when the answer is
     entered, which can be hours after the run; anything changed in between is stamped as read. Fixed: `--blind`
     writes each item's digest to stderr as it prints the input, the run saves it beside the prompt, and the brief
     has `read` entered from that saved line.
