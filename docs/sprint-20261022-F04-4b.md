### The mechanism (D-mech)

- **The record.** `tests/open-sets.json`, hand-kept: `{"module.NAME": "one-line reason"}` for every *open* set — a
  heuristic sample whose completeness is not defined. The census reads it and writes each unread entry's reason
  into `tests/derived-sets.json`, plus a count `unread_closed`: unread sets with no reason.
- **The test refuses:** an unread set with no reason (`unread_closed` ceiling **0**) — which is also how a new set
  must be classified the day it is written; a reason naming a set that is not in the unread column (stale); an
  empty reason. `UNREAD_AT_MOST` falls to the number of open sets.
- **A closed set** — a vocabulary something outside it states in full: a standard, an API's documented values, the
  registry, this tool's own outputs — leaves the unread column by derivation (it leaves the census) or by a reader in
  `tests/test_closed_sets.py` (or a module next to the code it holds) that asserts its membership against that source.
  A standard vocabulary is synced to a dated snapshot first (the owner, 2026-10-22: "Синхронизировать", "То же
  правило").
- Mutations: one reason deleted → red; a reason for a set that is read → red; a new unread literal in a scratch copy
  of a script → red; `unread_closed` ceiling raised is the only way past.
