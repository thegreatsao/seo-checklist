## Scope

Twelve `inherited` numbers that do decide a verdict, each traced to the item it moves, checked for a published
standard, and asked whether a corpus this machine can reach would settle it. None has a standard: Google
publishes no word count, no URL length that costs anything and no `llms.txt` metric, and the `llms.txt` proposal
names none. For each, what a corpus would show is a distribution of what sites publish, and the claim each number
makes is a different one — *too thin for its purpose*, *too long to read*, *useful to a model* — which no
distribution of practice answers. So each goes to `convention` with that argument written, not to `measured`.

| Number | Script | Decides | What a corpus would show, and why it does not settle the line |
|---|---|---|---|
| `MIN_PARAGRAPH_WORDS` 8 | `article_seo` | KW-076: which paragraphs are the body the keyword is sought in | where prose begins is the field's definition, not a property of pages |
| `COLLECTION_THIN_WORDS` 150 | `collection_page_checker` | AR-154 WARN (a `warning`) | the spread of copy stores write; how many deserve a warning is the choice |
| `THIN_CONTENT_WORDS` 300 | `seo_common` | CN-039 (WARN ≤ 5 pages, FAIL past) | what sites publish, not when a page is too thin; Google says length is not what it rates |
| `THIN_CONTENT_THRESHOLDS` | `duplicate_content` | only `default` is read, which is the number above | — the table decides nothing its default does not |
| `MAX_URL_CHARS` 115 | `url_quality` | AR-147 `short`, AR-155 `long_url`, CI-012 −12 | what lengths sites use; no engine prices a length (sitemaps allow 2,048, HTTP 8,000) |
| `MAX_PATH_SEGMENTS` 5 | `url_quality` | the same three, `deep_path` | how a site names its sections; too many is a readability call |
| `MAX_SHORT_PARAMS` 2 | `url_quality` | AR-147 | Google states no count; three reads as a filtered view |
| `GOOD_DESCRIPTION_CHARS` 50, `MIN_SECTIONS` 3, `GOOD_LINKS` 5, `MANY_LINKS` 10, `MIN_CONTENT_BYTES` 200 | `llms_txt_checker` | GEO-002 (`quality.score ≥ 60`), +5 each | adoption, not what a model reads; each moves GEO-002 only for a file missing title, description or links |

Checked against the code while writing (each line says only what was read): CN-039's rule (`thin_pages eq 0`,
warn `lte 5`), AR-154's (`none_severity` critical/high/medium, warn critical/high), CI-012's score
(`100 - 12 × flags`), GEO-002's arithmetic (title 20 + description 20 + links 20 = 60; without a title, 55 plus
any one bonus). `MIN_CONTENT_BYTES` compares `len` of the decoded text, characters, which its line now says.
