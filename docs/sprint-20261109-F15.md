## Per batch, every time

- Red first: the batch's tests fail on the commit before it (the count recorded below), pass after.
- A changed rule moves the registry version: `checklist.json` rebuilt (`tools/build_checklist.py`), and in the same
  commit `tests/census.json` (`tests/verdict_census.py --out`), `tests/inert-findings.json`, `tests/fixtures/
  expectations.json`'s stamp (and any `expect` the change moves, with its reason), the item's first reading in
  `item-readings.json` (the `check` copy and the reading), `script-output-shapes.md` where a field changed, and a
  CHANGELOG "Unreleased" entry naming the new registry version (`test_registry` reads the newest entry).
- Codex reviews the batch's diff (fresh session, `gpt-6.1-sol`, high, read-only); findings fixed red first, re-review
  until "ship".

- Local commits only: no push, tag or version bump (the owner decides releases).
