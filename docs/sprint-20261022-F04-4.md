### GOV-3 — 80 unread sets; "read" means imported

The Reader line: a census of module-level upper-case literals (183 sets, 103 read, 80 unread in the record), a
ratchet on the unread column, "read" = imported by a test. Holding the requirement in full means every set that
decides behaviour is derived or has a reader that says what belongs in it. Reading the 80 found, before anything ran:

- **D3-a, a verdict bug in an unread set.** `hreflang_checker.VALID_LANG_CODES` is labelled ISO 639-1 and holds 108
  entries (two of them three letters, unreachable behind `len(lang) == 2`); ISO 639-1 has 184. `VALID_REGION_CODES`
  is labelled ISO 3166-1 alpha-2 and holds 199; the standard has 249. A missing member is a High issue: expected
  `hreflang="fo"` (Faroese) to read "Unknown language code 'fo'" and `hreflang="en-GI"` (Gibraltar) "Unknown region
  code", each a High issue on SE-121/122's path. Red test first, then the sets completed to the standards with the
  standard's cardinality as the reader (a forgotten member changes the count). **Verdict move**: a valid code that
  read as an error no longer does (CHANGELOG note in the plan file).
- **D3-b, one concept, several copies, disagreeing.** Expected from reading: the deprecated / restricted schema types
  in three places (`article_seo.DEPRECATED_SCHEMA`/`RESTRICTED_SCHEMA`, the same two names *inside a function* in
  `parse_html.py`, `rich_results_guard.DEPRECATED_TYPES`/`RESTRICTED_TYPES`) — `HowTo` deprecated in two and
  restricted in one, `PracticeProblems` in two and `PracticeProblem` in one, `Dataset` in one; the AI crawlers in two
  (`robots_checker.AI_CRAWLERS` 13, `ai_crawler_policy_matrix.AI_CRAWLERS` 15, neither a subset of the other); the
  facet / filter parameters in three (`url_quality.FACET_PARAMS` 12, `faceted_nav_audit.FACET_KEYS` 13,
  `collection_page_checker.FILTER_PARAMS` 10). Where one copy is the tool's statement of an external fact (schema
  deprecations, crawler tokens), the others become derivations of it; whether that moves a verdict is measured
  first, and a move beyond what is said here goes to the owner.
- **D3-c, the census is blind to a function-local set.** `parse_html.py`'s two schema sets are bound inside a
  function, so the census does not count them. Expected: widening the census to upper-case names bound to a literal
  inside a function finds more than these two; how many, unknown.
- **D3-d, closed and open.** Every unread set is classified in `tests/derived-sets.json`: **closed** — it describes a
  complete vocabulary something can state (a standard, the registry, an API's documented values, this tool's own
  outputs) — gets a derivation or a reader asserting membership against that source; **open** — a heuristic sample
  whose completeness is not defined (stopwords, generic anchor phrasings, known tag vendors) — carries a one-line
  reason in the record. The test refuses an unread set with no class, an open set with no reason, and any unread
  closed set (ratchet to **0**). Expected: roughly half closed. A set classified open that is in fact closed is the
  way this could hide a verdict bug, and the reviewer is asked exactly that.
- **Narrowed, and filed:** an open set's completeness is a convention, said in the record, not held; "read" for an
  open set stays "imported".
- Expected after: `enforced`, narrowed, if every closed set is held. **Verdict moves:** D3-a, and D3-b only as
  measured and recorded.
