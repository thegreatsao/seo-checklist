## Scope

1. **The brief**, `skills/seo-checklist/tools/second-reading-brief.md`: the fixed prompt Codex gets, in two parts.
   - *Blind pass:* per item the title, the check (registry JSON), the `measures` sentence (or none) and the script's
     source; Codex returns, per item, a verdict — `answers` (the asserted path decides the title's question),
     `measures` (it decides less, and the `measures` sentence states accurately what it decides instead) or `owed`
     (neither: the item needs repair) — with its reasons. It is told to use only the input and the helper modules
     the script imports.
   - *Open pass* (the same Codex session, resumed): the first reading's verdict, reading and shape answers; Codex
     returns, per item, `none` or a dispute naming what the first reading gets wrong.
2. **Read-only options** in `audit_item_readings.py`: `--blind ID [ID ...]` prints the blind input of each item, each
   script's source once; `--open ID [ID ...]` prints each first reading. Built on a pure function the calibration
   also calls with the `v0.104.0` registry and sources. Neither writes anything.
3. **Calibration** (Q4, ruled): the seven pairs `TheShapesWouldHaveExposedEveryItemRepairedByHand` holds — GO-137,
   BL-083, MB-096, MB-097, MD-189, CI-016, MD-186 — with title, check and script source as at `v0.104.0`, mixed with
   seven current controls — CN-065, MS-030, CI-004, MS-028 (`parse_html.py`), CN-036, CN-035, MB-103
   (`rendered_audit.py`): two `measures`, five `answers`, every shape but `existential` firing among them. Item ids
   are replaced by shuffled labels. Codex runs blind on all fourteen; then the open pass on the seven controls.
   - **Bar:** all seven defective pairs get the blind verdict `owed` (none of them carried a `measures` sentence, so
     `owed` is the only verdict that names a defect); at least six of the seven controls are *undisputed* — blind
     verdict equal to the first reading's and no dispute in the open pass.
   - If the bar fails: no second reading is entered, the outcome is recorded here, and the batch stops for the owner.
4. **Second readings**, if the bar holds: every rule-carrying item of `parse_html.py` (14), `rendered_audit.py` (8)
   and `pagespeed.py` (7) — 29 items, the controls among them read in the calibration session. One Codex session per
   script group, blind then open. Each entered by hand: `reader` `codex gpt-6.1-sol high`, `session` the Codex
   session id, `verdict` the blind verdict, `dispute` the open pass's when not `none`, `read` from `--digest ID`.
   Disputes are listed for the owner below and not resolved.
5. **Where Codex reads from.** Not the repository: a scratch copy of `skills/seo-checklist/scripts/` at `HEAD` (no
   readings, tests, docs or history to look at), `--skip-git-repo-check`, `-s read-only`. For calibration, the
   current versions of the four calibration scripts are removed from that copy, so their repairs cannot be read;
   their `v0.104.0` sources are in the prompt, and their helpers are the current ones.
