## Scope

The fourteen `inherited` numbers that bound how much of a site a script reads. Each is a request budget, and the
argument that can be written for it is the same: past the cap the script sets `truncated`, and
`checklist_runner.py` (`input_truncated`) turns a PASS by absence into NO_DATA and marks a FAIL's count as a floor.
Where that holds, the number decides how often an audit says "not fully read", not which way a verdict falls, and it
is a `convention` with that judgement written out.

Per constant, before its line changes:

1. The script sets `truncated` when this cap stops the reading (or, for `RETRIES`, `DEFAULT_TIMEOUT`, `MAX_MESSAGES`,
   the path by which the number reaches a verdict is named instead).
2. A test drives the cap and sees `truncated`; added where none exists.
3. Every registry item that reads the script either passes by absence (so the runner withholds it) or its PASS on a
   capped input is shown not to depend on the unread part.

A constant that fails any of the three stays `inherited`, and why goes into this file under "Left inherited".

Files: the fourteen scripts' basis lines, `tests/` (new cap tests, `test_inherited_basis.py` ceiling),
`tests/known-issues.json` (the five-way distribution), the prose that states the counts (`ROADMAP.md`, `README.md`,
`openspec/specs/governance/spec.md`, whatever `tests/test_prose_counts.py` holds), then the release.

## Left inherited

- `gsc_cannibalization.py` `ROW_LIMIT`: MS-023 and KW-071 pass by absence and are withheld, but KW-070 and GO-139 read
  `branded.ranks_first` (`truthy`) off the same 5000 rows. The branded query judged is the one with the most
  impressions among the rows read, so a truncated window can pick a different query or miss the homepage's row, and
  the runner withholds nothing for a `truthy` rule. The cap can move those two verdicts.
- `site_crawl.py` `DEFAULT_MAX_PAGES`, `DEFAULT_DEPTH`: every crawl-fed item but one passes by absence or reads the
  entry page only. LO-198 (`high`, `local_business_nodes gte 1`) fails when no crawled page carries LocalBusiness,
  and `check_local_business_inventory` passes no `truncated` on, so past the cap a FAIL is reported for markup that
  may sit on a page never read. Filed as F08.
