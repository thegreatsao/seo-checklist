## Declared before anything was run

Written on `d407aba` from each item's title, its script's name and its recorded answers in `tests/census.json`,
before any rule or script was read and before the census was re-taken. A later reading may contradict a line
here; the line stays and the contradiction is recorded under "Outcome", because an expectation corrected by the
output it predicts is a tautology.

Vocabulary: **cannot fail** — the rule as written cannot report FAIL on any site; **corpus lacks** — the rule can
fail and no served tree carries the shape; **harness limit** — the shape needs something the static server cannot
serve today; **structural: needs X** — the item cannot answer offline without the named external input;
**defect** — the item could answer offline and does not.

## Scope

- Re-take the census on `d407aba` (`tests/verdict_census.py`) and record the before numbers.
- Never-FAIL: for each, read the rule and its script; a fixture that fails it for the reason its title names, or
  a rule fix with a red test first, or a `cannot_fail` declaration only where the rule passes by design.
- Never-answered: a fixture that makes it answer, or its external input named where the census reads it, held by
  a test, so an item that could answer offline and does not fails the build.
- Ledgers: `tests/census.json` re-recorded by its tool, ROADMAP's Clause 1 table and prose, the corpus README,
  `test_prose_counts`, spec-debt.
- Release 0.175.0 locally (no push).
